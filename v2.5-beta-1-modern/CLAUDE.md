# CLAUDE.md — v2.5-beta-1-modern

Modernized port of Microsoft Chat / Comic Chat 2.5 beta-1 (June 1998): a Win32 x86 MFC app
(`CChat.exe`) that turns IRC traffic into live comic panels. This folder is a snapshot of the
sibling `../v2.5-beta-1/` (kept untouched as the historical reference) with just enough changes
to build and run on current Visual Studio. See `README.md` for the full change log.

Windows-only: nothing here builds or runs on Linux. Don't try to compile in a Linux sandbox;
review changes by reading and keep edits minimal and consistent with the 1998 code style.

## Build

From a **32-bit** VS developer prompt (needs MSVC + MFC + x86 **Spectre-mitigated** MFC libs):

```bat
call "<VS>\VC\Auxiliary\Build\vcvars32.bat"
cd v2.5-beta-1-modern
nmake /f chat.mak CFG="chat - Win32 Release"   REM -> Release\CChat.exe (what CI builds)
nmake /f chat.mak CFG="chat - Win32 Debug"     REM -> Debug\CChat.exe (default if CFG omitted)
```

- Static MFC (`/MT` / `/MTd`), no precompiled headers, `/Zc:forScope- /Zc:strictStrings-`
  (legacy C++ semantics — new code must tolerate both).
- **No header dependency tracking.** After editing any `.h`, delete the `Debug\*.obj` /
  `Release\*.obj` files (or the whole output dir) and rebuild.
- `icchat_i.c` is generated by MIDL from `base\icchat.idl` (also regenerates `icchat.h`, which
  is committed). The `.res` is built from `chat.rc`.
- Headers such as `ccommon.h`, `cdebug.h`, `dib.h`, `format.h`, `llist.h` and `zlib.lib` come
  from `..\artifacts\inc` and `..\artifacts\lib\i386`, so the folder is **not** self-contained.
- To add a source file you must add its `.obj` to the `OBJS` list in `chat.mak`; the makefile
  does not glob.
- There are no unit tests. CI (`../.github/workflows/build-modern.yml`) builds Release on
  `windows-2022`, packages it (`../scripts/package-modern-builds.ps1`) and launches the exe from
  random folders (`../scripts/smoke-test-modern-builds.ps1`). It triggers on changes to this
  folder.
- Runtime needs `comicart\` (`.avb` characters, `.bgb` backdrops) next to the exe, or one
  directory above it (the dev `Debug\` layout).

## Layout

Flat folder of ~90 `.cpp` / ~85 `.h` files plus a few subdirs.

| Path | What it is |
|---|---|
| `chat.mak` | The nmake build (replaces the NT DDK `sources`/`dirs`/`base\makefile`, which are leftovers and unused) |
| `base/` | `icchat.idl` (COM interface fed to MIDL), `icbcore.idl`, `imsconf2.idl`, old DDK `sources`/`makefile` |
| `res/`, `chat.rc`, `resource.h` | Icons/bitmaps, dialogs, menus, string table (`chat.rc` is ~134 KB; `strings.txt` is a text dump) |
| `comicart/` | Bundled characters (`.avb`) and backdrops (`.bgb`) |
| `artpack1/` | Art Pack 1 characters (`archive/` has the source `.bmp`s) |
| `cchat.hlp/.cnt/.rcv`, `readme.*`, `irc*.txt`, `rtwsupport.txt` | Help file and original docs/IRC notes |
| `chat.reg`, `oldchat.reg` | COM / file-type registry entries |
| `chatver.h`, `chatver.rc` | Version stamp (hand-written replacement for the DDK-generated one; says 3.0) |

### Source by subsystem

- **App / frames / UI shell:** `chat.cpp/h` (`CChatApp`, `InitInstance`, settings), `MainFrm`,
  `childfrm`, `ipframe`, `chatbars`, `coolbar` (rebar), `tabbar`, `status`, `ui.h`, `defines.h`.
- **Document / views (MFC doc-view):** `chatdoc.cpp/h` (`CChatDoc`, session state),
  `chatview`, `textview` (RichEdit text mode), `pageview` (comic page, wheel scroll,
  panels-per-row auto-fit), `userlist`, `roomlist`, `saywnd` (input), `whisprbx`.
- **Comic engine:** `panel.cpp/h` (`CPanel`, `CPage`), `avatar`, `avbfile` (`.avb`/`.bgb`
  parsing; mirrors `../artifacts/avtools/avbfile.cpp`), `backdrop`, `balloon` (word balloons,
  international wrapping), `spline`/`splinutl`, `traj`, `vector2d`, `bbox`, `bodycam`
  (emotion wheel), `textpose`, `dib`, `arc`.
- **Protocol layer:** `chatsrv.cpp/h` (connection/server abstraction over MFC sockets),
  `ircsock.cpp` (socket + SSPI auth), `ircproto.cpp/h` (`CIrcProto`, IRC parsing),
  `protsupp.cpp/h` (largest file; shared protocol handling, message → panel dispatch),
  `chatprot.h`, `userinfo`.
- **Rules & automation:** `rules.cpp/h` (rule sets/actions), `actions.cpp/h`, `autopage.cpp/h`
  (automation property pages UI), `notif`/`notipage` (notifications), `motd`, `filesend`,
  `webreq` (HTTP).
- **OLE / embedding:** `binddoc`, `binditem`, `bindipfw`, `bindview`, `bindauto`, `binddcmt`,
  `bindtarg`, `mfcbind`, `oleobjct`; public automation IDs in `mschat.h`.
- **Dialogs / settings:** `setupdlg`, `proppage` (property sheets), `sounddlg`, `colordlg`,
  `txtfntdg`, `chanprop`, `admindlg`, `chicdial`, `bothdlg`.
- **Intl / misc:** `jis2sjis`, `sjis2jis`, `intl.c`, `mcithrd` (MCI sound thread),
  `dlylddll.c` (delay-load thunks), `urlutil`, `dpiscale.h`, `safectype.h`.

Largest files, and where behavior is most likely to live: `protsupp.cpp`, `rules.cpp`,
`autopage.cpp`, `ircsock.cpp`, `chat.cpp`, `chatsrv.cpp`.

### Files present but NOT compiled

`semantic.cpp` (a ~100-line stub — the comic-layout expert system is *not* here), `nmproto.cpp`
(NetMeeting; gated by `CB32SUPPORT`, off), `cache.cpp`, `cllist.cpp`, `dumbwnd.cpp`,
`guids.cpp`, `script.cpp`, `url.cpp`, `urlfind.cpp`, `wmini.cpp`, `bothdlg.cpp`. Check
`chat.mak` `OBJS` before assuming a file affects the binary. Note the header comment in
`chat.mak` says `dlylddll.c` is excluded, but it **is** built.

## Conventions and gotchas

- Every `.cpp` starts with `#include "stdafx.h"`. All strings are ANSI `char*` (`_MBCS`,
  no Unicode); Japanese via runtime SJIS/JIS conversion.
- Comic drawing coordinates are TWIPs (1440/inch); some UI uses hardcoded pixels.
- Keep `//{{AFX_...}}` ClassWizard blocks intact. Keep `chat.reg` and the GUIDs in
  `base/icchat.idl` consistent when changing automation interfaces.
- The app is deliberately **DPI-unaware** (no `SetProcessDPIAware`); `DpiScale()` is a no-op
  at 96 DPI. Don't "fix" scaling piecemeal.
- Use `safectype.h` wrappers for `is*` functions (high-byte chars crash the modern debug CRT).
- `stdafx.cpp` carries the Common Controls v6 manifest; without it the rebar toolbar fails
  to create and startup breaks. `stdafx.h` must NOT remap `tagLVITEMA`/`TCITEM`.
- `ID_EM_*` IDs in `resource.h` were moved out of MFC's reserved range; don't renumber back.
- Debug builds install a CRT report hook to swallow legacy assertion dialogs; prefer testing
  persistence/shutdown behavior in Release.
- Art/character downloads from Microsoft servers are intentionally disabled (servers are gone).
- No native TLS yet (see `../docs/tls.md`; reference impl in `../v1.0-pre-modern/tlssock.cpp`).
- Don't edit `../v2.5-beta-1/`; it is the historical record. Shared fixes live in
  `../artifacts/core/` (e.g. `urlutil.cpp`), which affects other trees too.
- `../.github/copilot-instructions.md` describes the *original* trees; where it conflicts
  with this file (e.g. `semantic.cpp`, `chat.dsp`, build system), this file wins.
